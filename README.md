# MoveAWheel · Passability Map

카카오맵 위에 휠체어 노면 등급과 위험도를 표시하고, 출발·도착 두 점 사이의 최단·절충·안전 경로를 비교하는 샘플입니다.

**현재 게시 주소:** https://moveawheel-passability-harry.harryfriend0000.chatgpt.site/

## 기능

- 중심 좌표 `36.365473, 127.338021` 반경 1km를 기본 화면으로 표시합니다.
- 지도 임의 위치에서 출발·도착을 지정합니다. 경로 구간을 클릭하면 왼쪽 상세 패널이 펼쳐집니다.
- 최단 거리, 최적 거리(안전 + 거리 절충), 안전 거리와 이동거리·예상 시간·평균 및 최대 위험도를 표시합니다.
- `다시 두 점 찍기`는 기존 경로를 유지하면서 두 점을 다시 선택하고, `초기화하기`는 전체 선택을 지웁니다.
- 대로변은 70%가 1–2등급, 골목·이면도로는 70%가 3–5등급이 되도록 공간별 시연 등급을 배치합니다.

## 데이터와 계산

카카오 도보 API의 기본 후보 3개와 주변 경유지 탐색 후보 최대 6개에서 실제 경로 좌표를 수집합니다. 동일한 API 좌표에서만 연결한 방향 그래프를 만들고, 경유지 왕복 경로를 그대로 표시하지 않습니다.

- 최단: 구간 길이의 합을 최소화합니다.
- 최적: `길이 × (1 + 2 × 위험도/100)`의 합을 최소화합니다. 구간을 조합한 제3 경로도 가능합니다.
- 안전: 우회 한도 `max(최단 × 1.5, 최단 + 80m)` 안에서 `길이 × (0.000001 + 위험도/100)`의 합을 최소화합니다.

위험도는 구간별 정적·동적 위험도 중 최댓값이며, 평균은 거리 가중 평균입니다. 통행 불가·미확인·사용자 조건에 맞지 않는 구간은 그래프 탐색에서 제외합니다. 조건에 맞는 연결망이 없으면 기본 후보의 조건 미충족 상태를 표시합니다. 세 옵션이 같은 길을 선택할 수도 있습니다. 최적성은 수집한 연결망 안에서만 성립하며 전체 인도망을 보장하지 않습니다. 예상 시간은 카카오 구간별 시간을 비례 배분해 합산합니다.

**노면·위험도는 기본적으로 시연 값입니다.** 카카오 지도와 도보 경로 자체가 인도 폭·단차·실측 안전도를 제공하는 것은 아닙니다. 실제 모델 JSON을 연결하면 최근 24시간·신뢰도 80% 이상·3m 이내·방향 일치 관측이 시연보다 우선합니다. OSM 샘플 모드의 도로 데이터는 © OpenStreetMap contributors, ODbL이며 차도 중심선이 인도를 의미하지 않습니다.

## 로컬 실행

Node.js 22 이상이 필요하며 런타임 외부 의존성은 없습니다.

1. `.env.example`을 `.env`로 복사하고 `KAKAO_REST_API_KEY`를 설정합니다.
2. `npm start`를 실행하고 `http://127.0.0.1:3000`에 접속합니다.
3. 카카오 개발자 콘솔에 해당 JavaScript 키의 도메인을 등록합니다. 기본 JavaScript 키는 브라우저용이며, 지도 연결 메뉴에서 자신의 키로 변경할 수 있습니다.

REST API 키는 브라우저 코드와 저장소에 넣지 않습니다. `.env`는 Git에서 제외됩니다.

## 배포

현재 게시 사이트는 API 서버를 함께 제공하며 REST 키를 서버 비밀 설정으로 관리합니다. 이 GitHub 저장소는 소스 보관용입니다. GitHub Pages는 서버 API를 실행하지 않으므로 정적 파일만 올리면 실제 도보 길찾기가 작동하지 않습니다.

다른 호스팅으로 이전할 경우 Node 서버를 운영하거나, 제공된 `wrangler.jsonc`로 Cloudflare Workers에 배포할 수 있습니다. Workers에서는 `npm run build` 후 배포 계정의 `KAKAO_REST_API_KEY` secret을 설정해야 합니다. 새 주소는 카카오 JavaScript SDK 허용 도메인에 추가해야 합니다.

검증: `npm test`, 빌드: `npm run build`.
